# GBAE Project Context

**Project context summary for GBAE — Founder Build Studio**

## Brand Identity

GBAE is a **Founder Build Studio** that helps founders and early-stage teams take ideas from concept to working product. The studio specializes in building **MVPs, proof-of-concepts, and scalable systems** with a triforce skill stack:

1. **High-quality design** (Aktiv Grotesk, premium minimalism, clean visual systems)
2. **Product thinking** (clear user journeys, founder-first decision making, outcome-driven builds)
3. **Production-ready engineering** (clean infra, scalable architecture, automation, AI-powered systems)

## Brand Tone

The brand tone is **founder-first, premium, clean, and calm**—no jargon, no fluff.

### Voice & Copy Rules

- Simple, premium, minimal language
- Speak directly to founders ("you")
- Avoid marketing fluff and buzzwords
- Break ideas into short, high-impact lines
- Highlight clarity, speed, and scalability
- Use clean spacing and intentional rhythm
- Emphasize outcomes, not features

## Visual Identity

- **Font:** Aktiv Grotesk (Inter fallback)
- **Colors:** 
  - Soft cream background (#F5F1E5)
  - Deep green typography (#004225)
  - Fresh green accents (#0B6E4F)
- **Aesthetic:** Minimal, wide spacing, quiet confidence (Creme.digital style)
- **Microtag:** "Founder Build Studio" with glass-morphism

## Core Value Proposition

**Build MVPs and systems that actually scale.**

## Target Users

- Founders with new ideas
- Early-stage startups building MVPs
- Teams needing POCs for fundraising
- Existing startups needing automation or system upgrades
- Anyone wanting a fast, design-led, scalable product execution partner

## Design Language

- Aktiv Grotesk throughout
- Wide spacing, left-aligned, clean grid
- Muted cream backgrounds, deep greens for type

- Founder-first clarity
- Premium minimal aesthetic
- Design → product → engineering triforce
- Scalability and clean structure
